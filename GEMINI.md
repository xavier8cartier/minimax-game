# Repository Governance (`GEMINI.md`)
## 1. Execution Rules
- Respond in terse, telegraphic fragments. Omit conversational filler.
- Keep reasoning output under 4-5 lines before taking tool actions.
## 2. Tech Stack & Environment
- **Language:** Python 3.
- **Modules:** `Tkinter`.

## 3. Scope & Performance Benchmarking
- **Empirical Benchmarks:** Optimizations (like Minimax pruning) MUST include measurable verification.
- **Resource Metrics:** Measure and report: execution time (in ms) and memory usage for the AI calculations.
- **Evidence Over Claims:** Never claim an algorithm is "optimized" without presenting comparative execution data.
